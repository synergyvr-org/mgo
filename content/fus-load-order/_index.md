{{< github "Kvitekvist/FUS" >}}FUS{{< /github >}} is, in its authors' words, "a fundamental and modular modlist for Skyrim VR made by Kvitekvist and Cangar." Check out their README on GitHub for all the details, a link to their Discord, and a video guide for installation.

Here we present the Mod Organizer 2 load order for each of the five FUS variants, calling out the differences between each one. If you want to see exactly what's in each list (and which mods ship enabled in each one), this is where to look.

On each of these pages, the numbered sections start closed, so you get FUS's own instructions and an outline of its sections before you get all of its mods. Open the sections you're curious about, or hit {{< btn-inline >}}Expand all{{< /btn-inline >}}. Type in the filter box to search a list by name or version, and once you've spotted what you were after, click its row (or the {{< btn-inline crosshairs >}}Show in list{{< /btn-inline >}} button at the right edge) to drop the filter and see where that mod actually sits in the load order.

## FUS DAH  (Basics + Gameplay)

Includes the basics and some gameplay changes, but no notable visual changes.
{{< /chapter-heading >}}

{{< chapter-heading href="fus-ro-dah" >}}
## FUS RO DAH (Basics + Visuals + Gameplay)

All of the visual enhancements _and_ the gameplay overhauls. Most of the optional mods are enabled by default, but the FUS team doesn't necessarily recommened leaving it that way. You're meant to disable some of the optional mods according to your own taste.
{{< /chapter-heading >}}

## CANGAR

The FUS RO DAH list with Cangar's personal selection of optional mods.
