A filterable, categorized reference of the console commands worth knowing. New to the console? Start with [Console](/reference/console) for how to open it in VR and the basics of targeting and IDs.

A few conventions used below:

- **`player.`** runs a command on your own character. Drop the prefix and most of these act on whatever you've _targeted_. In VR you target with `prid <refID>` rather than a mouse click; see [Console](/reference/console#targeting-without-a-mouse) for how.
- Text in **`<angle brackets>`** is a value you supply, like an ID, a number, or a skill name.
- Toggle commands (the ones starting with `t`) flip on and off; run the same command again to reverse it.
