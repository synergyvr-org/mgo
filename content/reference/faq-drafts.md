## Getting Started

{{< disclosure title="Can I still play Skyrim's original opening? I'm finally awake, and I like it when people point that out." >}}
Yes, it's an option in both Live Another Life (4.0 RC2 and earlier) and Alternate Perspective (4.0 RC3 and later).

In [Alternate Start- Live Another Life](/first-launch/alternate-start-aslal/) (all MGO versions up to and including 4.0 RC2), the vanilla start is clearly labeled: **I got caught crossing the border illegally. [Vanilla Start]**

With [Alternate Perspective](/first-launch/alternate-start) (MGO 4.0 RC3+), the true vanilla start is nested under the **Dragonborn** option. If you want an _almost_ vanilla opening, but without the cart ride, you'll see options for starting in Helgen Keep there as well. (And there's always Alternate Perspective's default, where you can witness Alduin's attack as a bystander, rather than a prisoner.)
{{< /disclosure >}}

## Making it yours

{{< disclosure title="Can I add my own mods?" >}}
During the beta, the team asks that you don't, so that feedback reflects the list as built. Once the list is released for real and you start feeling brave:

- Check the advice in [Will This SE Mod Work in VR?](/tutorials/se-mods-in-vr) for vetting.
- Check [Installing a Mod](/tutorials/installing-a-mod) for the how.
- Check [A Sandbox Profile](/tutorials/sandbox-profile) for tips on changing the load order with minimal (but not zero) risk.
{{< /disclosure >}}

{{< disclosure title="Can I use a RaceMenu preset someone shared?" >}}
Yes, but whether it will look the way you want depends. If the preset is already packaged as a mod, just add it. If it's a loose {{< file file-lines >}}.jslot{{< /file >}} file, stick it into a mod in {{< file folder-open >}}SKSE\Plugins\CharGen\Presets{{< /file >}}. Once you have it, load it from RaceMenu's **Presets** tab. Keep in mind, a preset built around Racemenu plugins or hair or skin mods that MGO doesn't include will not look right, so presets from fellow MGO players work best. Full steps (and the rest of the fine print) at [RaceMenu Presets](/tutorials/racemenu-presets).
{{< /disclosure >}}

{{< disclosure title="A mod in the list has an update on Nexus. Should I update it?" >}}
It may be risky. MGO includes the versions that it does on purpose, and updates arrive with the next list release, tested as a set. See [Updating a Mod](/tutorials/updating-a-mod) for the exceptions.
{{< /disclosure >}}

{{< disclosure title="Do I need to run BodySlide?" >}}
Only if you add armor or clothing mods of your own. Everything in the base list comes pre-built. See [BodySlide](/tutorials/bodyslide).
{{< /disclosure >}}

## When things go wrong

{{< disclosure title="The game crashed. Now what?" >}}
If it crashes once? Well, that may just be Skyrim being Skyrim. Load your last save and carry on. If it repeats, see [Diagnosing a Crash](/tutorials/diagnosing-a-crash).
{{< /disclosure >}}
