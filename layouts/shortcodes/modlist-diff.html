{{- /* Shows what one modlist adds on top of another, computed from the two CSVs so it never drifts from the lists themselves. If the newer list also drops anything, that gets its own group at the end. `base` accepts a comma-separated list of CSVs, in which case the base is their union. That answers "is this list exactly its two parents combined?": {{< modlist-diff base="static/fus-ro.csv,static/fus-dah.csv" list="static/fus-ro-dah.csv" base-label="FUS RO + FUS DAH" list-label="FUS RO DAH" >}} Element ids are prefixed with `id-prefix` (defaulting to the base label), so several comparisons can share one page without colliding. `ignore` (regex) filters out per-list build artifacts that would otherwise show up as a difference in every comparison: each FUS variant ships its own Conflict Resolution patch and Synthesis output, named for that variant, so they always look "added" and "removed" at the same time.
